# Прошивка Arduino Uno

Для формування двох синхронних сигналів було використано ATmega328P на 16 МГц і Timer1 плати Arduino Uno. D9 (OC1A) керує верхнім масивом, D10 (OC1B) — нижнім, а D8 — входом очікування TB6612FNG. Номінальна частота — 40 кГц; прошивка підтримує 38–42 кГц і відносні фази 0° та 180°.

Timer1 працює в режимі Fast PWM 14 без дільника частоти. Для номінальної частоти:

```math
f=\frac{f_{\mathrm{CPU}}}{1+\mathrm{ICR1}}=\frac{16\,000\,000}{400}=40\,000\ \mathrm{Hz},\qquad \mathrm{ICR1}=399.
```

На 40 кГц обидва виходи мають коефіцієнт заповнення 50%. Інші задані частоти округлюються до цілого числа тактів таймера. Фокусування забезпечує геометрія, тому окремих фазових каналів для кожного випромінювача немає.

Послідовний інтерфейс працює на 115200 бод. Команда `F` задає частоту, `P` — фазу, `E` — стан увімкнення моста, `S` повертає поточний стан, `H` — опис команд. Після скидання міст вимкнений; зміна частоти або фази короткочасно вимикає його, а потім відновлює попередній стан. Некоректні аргументи та надто довгі рядки відхиляються.

Вихідний код міститься в `acoustic_levitator/acoustic_levitator.ino`.
